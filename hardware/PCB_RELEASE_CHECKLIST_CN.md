# PCB 投板放行清单

当前文件包含网络、真实焊盘、器件布局和内层平面定义，但尚未布线。Gerber 放行门槛如下，全部签字后才可建立 `FAB_RELEASED` 版本。

## 原理图

- [ ] 从 ST、Nuvoton、Winbond、Microchip、TI 的当前原厂数据手册逐脚复核。
- [ ] STM32G031F8P6 的 TSSOP20 复用脚与固件外设映射经过 CubeMX 验证。
- [ ] LSM6DSO 在 I²C 模式下 CS 拉高；SDO/SA0 地址脚固定，不悬空。
- [ ] LPS28DFW 的焊盘严格按 ST TN0018 复核；金属帽接地、O 形圈受力和顶层禁布区按原厂建议完成。
- [ ] NAU7802 的 AVDD=3.0 V、DVDD=3.3 V、六线桥 REF、输入共模与 320 SPS 配置复核。
- [ ] W25Q256 的 `/WP`、`/HOLD` 上拉与上电时序复核。
- [ ] 充电电流按实际电芯允许值设置；20 kΩ 仅代表约 50 mA 的候选值。
- [ ] 使用带保护电芯，或补充独立过充、过放、短路保护。

## 布局布线

- [ ] 四层建议：F.Cu 信号/器件，In1 整面 GND，In2 3V3/VBAT，B.Cu 低速信号。
- [ ] IMU 距板边、螺钉、弹性梁和磁性件足够远；器件坐标轴已在丝印标出。
- [ ] 压力传感器开孔上方无遮挡，所有铜/阻焊/外壳压紧区域满足数据手册。
- [ ] NAU7802 与桥路接口形成独立安静区，差分输入等长、短、成对，远离 LED 和充电回路。
- [ ] 每个电源脚就近去耦；Flash 和 MCU SPI 回路短且有连续参考地。
- [ ] 湿式触点设置隔离/串阻，盐水中不得带电暴露。
- [ ] 完成 4 层板厂能力规则 DRC，无未布网络，无未连接地岛。
- [ ] 板文件中当前 `segments/tracks=0` 的阻断状态已解除，全部飞线清零。

## 制造与首件

- [ ] 板厚 1.0 mm、ENIG、4 层叠层与 12 × 35 mm 外形得到板厂确认。
- [ ] 实际 SMT 厂料号锁定；BOM 中所有替代料逐项审批。
- [ ] Gerber/钻孔在独立查看器中复核，CPL 原点和旋转方向用装配图确认。
- [ ] 先做裸板短路检查，再限流 10 mA 上电。
- [ ] 分别验证 3V3、I²C 三传感器、Flash、充电、SWD、LED、应变桥。
