# 双端数据与全自动调参协议

## 目标

智能水中作为“钩侧教师传感器”，阿波作为待优化检测器。两端独立记录，回收后自动对时、自动生成标签、搜索阈值/滤波参数并在独立航次验证，避免人工逐段看波形。

## 采样建议

| 通道 | 阿波 | 智能水中 |
|---|---:|---:|
| 加速度/角速度 | 104 Hz | 208 Hz |
| 压力 | 50 Hz | 100 Hz |
| 张力 NAU7802 | — | 320 SPS |
| 电池/温度 | 1 Hz | 1 Hz |

所有样本使用 MCU 单调计时器的微秒时间戳。当前实现为HSI16/TIM2；LSE启动ready不表示这些时间戳已由LSE校准，`SAMPLE_FLAG_LSE_FAIL`仅反映启动尝试结果。每次开机记录设备 ID、固件哈希、量程、ODR、温度和校准系数。

## 同步

1. 下水前把两个设备固定在同一硬板上，同时做三次明显的手动敲击；两端都会记录高信噪比 IMU 脉冲。
2. 回收后用三脉冲序列估计时间偏移和时钟漂移，随后用整段低频运动互相关微调。
3. 若整段末尾再做三次敲击，可拟合线性漂移；长时间记录建议按分段仿射时间映射校正。

## 自动标签

- 正样本候选：水中张力高通/变化率超过自适应噪声门限，并满足 30–800 ms 的持续时间或冲量条件。
- 排除项：两端压力与 IMU 都表现为高度相干的低频周期运动，优先标为海浪/流致扰动。
- 不确定区：张力信号弱或两端同步质量差的事件不参与自动寻参，只保留供人工抽查。
- 真实“鱼讯”标签最终仍需钩况/摄像/提竿结果确认；张力只能提供可靠的钩侧机械事件标签，不能证明一定是鱼。

## 自动寻参与防止过拟合

1. 每个航次按完整时间块切成训练、验证、测试，禁止把相邻窗口随机打散。
2. 搜索阿波侧的频带、窗口、压力-姿态融合权重、启动/释放阈值和迟滞。
3. 优化目标为事件级 F1，同时约束每小时误报数与漏报率；不同海况分层统计。
4. 新参数只有在未参与寻参的下一航次仍优于旧参数时才自动升级，否则回滚。

## 建议二进制记录字段

`timestamp_us, sequence, ax, ay, az, gx, gy, gz, pressure_raw, tension_raw, temperature, battery_mv, flags, crc16`

原始数据不可覆盖；每次参数升级另存 JSON 清单，包含父版本、训练航次、指标和回滚条件。
